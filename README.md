# DayOut iOS

A small native iOS learning project built with SwiftUI.

The goal of this repository is to learn modern iOS engineering by understanding a working starter codebase first, then adding features incrementally.

## Current starter

- SwiftUI app entry point
- Explore screen
- Activity domain model
- Repository abstraction
- Mock repository
- Observable feature model
- Unit test target
- Architecture and onboarding docs

## Run locally

1. Clone the repository.
2. Open `DayOut.xcodeproj` in Xcode.
3. Select an iPhone simulator.
4. Press **Run**.

Start with [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md).
