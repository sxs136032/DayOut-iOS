# Learning Path

## Stage 0 — understand the starter
Swift syntax, structs, classes, protocols, SwiftUI views, state, Observation, async/await.

## Stage 1 — UI state
Add category filtering, empty states, and detail navigation.

## Stage 2 — networking
Replace mock data with `URLSession`, `Codable`, errors, and cancellation.

## Stage 3 — persistence
Add SwiftData and offline saved activities.

## Stage 4 — Apple frameworks
Add MapKit, Core Location, WidgetKit, and App Intents.

## Stage 5 — AI
Add a structured itinerary planner using Apple's Foundation Models framework where supported.
